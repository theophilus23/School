Production deployment checklist

  • Firebase or equivalent authentication and database rules.
  • Server-side role checks for admin, teacher, student and parent.
  • Private document storage with class/section access controls.
  • Firebase Cloud Messaging setup for Android push notifications.
  • Secure password reset, audit log, backups and consent/privacy policy.
  • Fee/exam filters based on real records; confirm recipient list before sending.
